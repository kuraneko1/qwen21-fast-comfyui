# 概念図の設計書（デザインの指定は含みません）

この文書は「**何を描くか**」だけを決めたものです。色・配置・フォント・線の太さといった見た目の指定は
一切含みません（それは描く側の自由）。描画は別のAIまたは人に任せてください。
文末の「**AIへの指示文**」をそのままコピーして渡せば、この内容の図ができます。

- 用途: リポジトリのREADME冒頭に置く画像（`docs/pipeline_ja.png` / `docs/pipeline_en.png`）
- 目的: 初めて見る人が、この環境で「何が動いているのか」を数秒で理解できるようにする
- 読者: ローカル画像生成に詳しくない人。図の中に専門用語の説明文は書かない（短いラベルだけ）
- 前提: 描くのは「実行時のデータの流れ」と「必要な重みファイルの役割」だけ。
  **速度の話・最適化の話・別の実行方法は入れない。**

## 3. 制約（守らないと使えない）

1. **1節・2節の要素と矢印だけを描く。** 追加の箱（クラウド、API、アプリ、モデル一覧、GPUの絵など）を
   勝手に足さない。
2. **文字を箱の外に出さない。** 入りきらない場合は折り返す（はみ出しは不可）。
3. 箱1つに入れるのは**3行まで**。ラベルは勝手に言い換えず、上の表の文言を使う。
4. 段の順番は**左→右で固定**: プロンプト → エンコーダ → 生成器 → VAE → PNG。
5. 配色は指定しない。ただし**凡例がないと意味が分からない配色（色で役割を区別する等）は避ける**。
6. 実測時間・ハードウェア名・別エンジンの話は**入れない**（READMEの本文に書いてある）。
7. **日本語版と英語版の2枚**を作る。箱の数・矢印の構成は2枚で完全に同じにし、文言だけ訳す。
8. READMEでは**幅800px程度**で表示される。その大きさでラベルが読めること。

## 4. 出力仕様

- 形式: **PNG・白背景**（透明背景にしない）
- 形状: 横長（例: 1200×600〜700程度）
- 文字は画像に直接描く（注釈レイヤーや別ファイルに分けない）
- ファイル名: `pipeline_ja.png`（日本語版）、`pipeline_en.png`（英語版）
